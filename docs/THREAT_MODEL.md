# Threat Model

## Status

This document uses STRIDE to describe material threats and planned controls. It does not claim that controls are currently implemented.

## Methodology

STRIDE categories are used as follows:

- Spoofing: pretending to be another user, service, provider, or integration.
- Tampering: modifying data, messages, artifacts, traces, or decisions without authorization.
- Repudiation: denying an action because audit evidence is missing or weak.
- Information disclosure: exposing tenant, credential, prompt, completion, trace, or review data improperly.
- Denial of service: making EvalForge or its dependencies unavailable or too costly.
- Elevation of privilege: gaining actions outside the actor's intended permissions.

## Highest-Risk Themes

The highest-risk themes are cross-tenant data exposure, broken object-level authorization, prompt or tool-output injection that drives unsafe actions, model-judge manipulation, cost amplification, and audit or gate tampering. Later milestones must treat these as acceptance-critical risks.
